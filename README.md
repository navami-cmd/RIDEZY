# RIDEZY 🚗

RIDEZY is a ride-booking web application prototype designed to provide a simple, interactive ride-planning experience. Users can enter pickup and destination locations, explore route information, compare estimated fares across vehicle categories, and interact with simulated ride features.

## ✨ Features

- **Location search:** Search for pickup and destination locations.
- **Route estimation:** Display estimated travel distance and duration.
- **Fare estimation:** Compare estimated fares across vehicle categories.
- **Fare breakdown:** View the base fare, distance charge, and estimated total.
- **Ride experience demo:** Explore simulated driver arrival, chat, and ride feedback.
- **Error handling:** Display helpful messages when locations or routes cannot be resolved.
- **Responsive interface:** Use the application on desktop and mobile screens.

## 🛠️ Tech Stack

- HTML5 — page structure
- CSS3 — styling and responsive layout
- JavaScript — application logic and interactions
- OpenStreetMap Nominatim — location search
- OSRM Routing API — route distance and duration

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use the **Live Server** extension in Visual Studio Code.
4. Enter a pickup location and destination to explore the demo.

An internet connection is required for the external location-search and routing services.

## ⚠️ Project Note

RIDEZY is a demonstration project. Fare calculations are estimates, and driver arrival, chat, booking, and emergency features are simulated. It does not connect users to real drivers or provide a real emergency-response service.
